## Reply to App Review (paste, attach the recording)

Thank you for the review. Answers to each item follow; the screen recording is attached.

1. Screen recording — attached. Captured on a physical Apple TV 4K running the
   current tvOS. It starts at app launch, shows the server list synced from the
   same iCloud account as our iPhone, opens a session, shows the live terminal on
   the TV, and shows the Fin agent view and its control strip. There is no account
   registration, no user-generated content, and no purchase on Apple TV.
   (If the reviewed build is today's 1789348237: the recording also shows Sign in
   with Apple on the server list and the SSH key arriving from the companion
   iPhone through the encrypted key vault.)

2. Purpose and audience — Fin is a terminal with an AI agent at the controls,
   for developers and operators who run their own computers. The Apple TV app
   is the big-screen view of that: it shows the servers the user configured in
   Fin on iPhone, iPad, or Mac (synced privately through the user's own iCloud),
   connects to one over SSH, renders the terminal for a living-room display, and
   lets the user watch a long build, a deploy, or the agent working through a
   task from across the room. The value is glanceable visibility of work that is
   happening on the user's own machines, without a laptop open.

3. Setup and access — There are no Fin credentials; the app has no login of its
   own beyond optional Sign in with Apple (see 4). To evaluate:
   a. On an iPhone or iPad signed into the same iCloud account as the Apple TV,
      install Fin (same universal purchase), add any reachable SSH server, and
      import its private key (ed25519 or RSA, OpenSSH format) from Files.
   b. Launch Fin on the Apple TV. The server appears within a moment via iCloud
      sync. On a fresh iCloud account that has never used Fin, the list is
      legitimately empty and shows "No Servers Yet"; that is the designed state.
   c. Select the server. On the reviewed build the SSH key is delivered to the TV
      through the key vault after Sign in with Apple on the server list; on the
      Sep 11 build the TV shows "Key needed" for servers whose key was not yet
      provisioned, and connects for servers whose key is available.
   d. Type with a paired Bluetooth keyboard, or use Fin on iPhone/iPad as the
      keyboard for what is on screen.
   A reviewer without an SSH server can still evaluate the synced server list,
   the connection UI, and the agent view; any Linux or macOS host with SSH
   enabled and a matching key pair works as the target.

4. External services, tools, and platforms —
   - Apple iCloud / CloudKit: private-database sync of the user's server list,
     agents, and settings between the user's own devices. Nothing is shared
     between users.
   - Sign in with Apple (optional, iOS/macOS/tvOS builds from Sep 9 on): creates
     a per-user account on Fin's control plane so the user's agent, goals, and
     notifications follow them across devices.
   - Fin control plane (operated by us on AWS: API Gateway, Lambda, DynamoDB,
     S3, with optional EC2 workers): relays messages, agent status, and push
     notifications between the user's devices and the user's agent, and can run
     the agent in the cloud when no user computer is reachable. It never carries
     the user's terminal session: SSH connects directly from the device to the
     user's server.
   - Apple Push Notification service: delivery of the agent's notifications.
   - AI models: Apple's on-device intelligence, or an OpenAI-compatible endpoint
     the user hosts themselves (LM Studio, Ollama, vLLM). We do not operate a
     model service and no third-party AI provider is called by the app.
   - StoreKit: in-app purchase on iPhone, iPad, and Mac (not on Apple TV);
     the entitlement is shared across platforms via universal purchase.
   No data providers, payment processors, or analytics SDKs are used.

5. Regional differences — None. The app functions identically in every region;
   there is no region-specific content or feature gating.

6. Regulated industry / third-party material — Not applicable. Fin is a
   general-purpose developer tool. It contains no protected third-party
   material; the terminal engine is open-source software used under its license.
