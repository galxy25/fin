# Citation-checker waivers — scripts/model-factory/labbook/check_citations.py
#
# Format:  <file> | <exact snippet from the offending line> | <reason>
#
# Keyed by TEXT, not by line number, so a waiver survives edits above it and
# dies the moment the sentence it excuses is reworded. Every waiver needs a
# reason; the checker refuses to load one without.
#
# A waiver is an editorial act on the record. There are exactly six reasons a
# branch name is legitimate in this book, and each entry below names which:
#
#   quoted-defect      The book is quoting a false sentence in order to correct
#                      it. Rewriting the quotation would erase the evidence.
#   asserted-absence   The citation's content is that the path does NOT exist
#                      at that revision. The checker failing to resolve it is
#                      the finding, not a defect.
#   shorthand-subject  The `main:…:N` form is named as a form, not used as a
#                      citation.
#   future-state       A claim about what becomes true when a branch merges.
#                      There is no revision to pin, because the event has not
#                      happened.
#   not-a-git-object   Hex that is a content digest or a model snapshot id.
#   corrected-elsewhere The sentence is a PUBLISHED defect that a later entry
#                      corrects. Append-only forbids rewriting it, so the
#                      waiver is a pointer: it must name the correcting entry,
#                      that entry must exist, and its `corrects:` front matter
#                      must list the entry being waived. check_citations.py
#                      enforces all three -- a waiver that points nowhere fails
#                      the run. Added by O013; see the README's step 5.
#
# Nothing else. If a new waiver does not fit one of these, the citation is
# wrong and wants pinning, not excusing.
